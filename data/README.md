# Dataset setup

Place `WA_Fn-UseC_-Telco-Customer-Churn.csv` in this folder before running the training script. The raw file is excluded from Git so the project does not redistribute customer-level data without confirming the source's current terms.

The filename corresponds to the IBM Telco Customer Churn sample dataset. One source is [IBM's telco-customer-churn-on-icp4d repository](https://github.com/IBM/telco-customer-churn-on-icp4d/tree/master/data). Check the source terms and provide attribution when you use or redistribute the dataset.
